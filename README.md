# Metro City v1.1

Three.js + TypeScript + Vite로 만든 오리지널 로우폴리 3D 도시 게임입니다. 외부 모델·음악·유료 API가 필요하지 않습니다.


## v1.1 도시 그래픽 업데이트

현재 열려 있는 `Metro-City-Play.html`을 새로고침하면 업데이트가 적용됩니다. 브라우저 저장 키와 파일 이름을 유지하므로 같은 파일/브라우저에서 플레이하면 기존 돈·보유 차량·미션 기록을 이어갑니다.

- 도심: 네 면의 창문, 층별 띠와 옥상 설비, 높이가 다른 빌딩 실루엣
- 주택가: 경사진 지붕, 굴뚝, 현관, 담장과 정원수
- 상업 지구: 차양, 상점 전면 간판과 쇼윈도, 전용 차고 외형
- 산업 지구: 창고 셔터, 외벽 보강재, 컨테이너와 배기 설비
- 공원: 분수, 화단, 벤치와 서로 다른 크기의 나무
- 도로: 아스팔트 질감, 타일 인도, 연석, 횡단보도와 정지선
- 조명: 절차적으로 생성한 그라데이션 하늘, 낮밤에 따른 창문 발광, 가로등의 빛 번짐·바닥 광원과 가까운 6개 실제 점광원, 야간 보조광
- 일시정지 메뉴: 낮 / 해 질 녘 / 밤 미리보기와 시간 고정
- 안정성: 일시정지 후 교통이 불필요하게 재생성되는 문제 수정, 인구 설정 변경 시 탑승한 차량 보존, 지원하지 않는 마우스 잠금 요청의 예외 처리

도시의 정적 물체를 재질과 구역 단위로 묶어 렌더링합니다. 외부 이미지·유료 에셋·인증 API는 사용하지 않습니다. 도로망과 미션 좌표는 유지했습니다.

실행용 단일 HTML을 다시 만들려면 다음을 실행합니다.

```sh
npm run build:play
```

프로젝트 폴더에 생성된 `Metro-City-Play.html`은 추가 서버 없이 브라우저에서 직접 열 수 있습니다. 메인 Vite 프로젝트는 기존 `npm run dev` / `npm run build` 방식도 지원합니다.

## 실행

Node.js 22.12 이상(또는 20.19 이상)을 설치한 뒤 이 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

터미널의 로컬 URL을 Chrome 또는 Edge로 여세요. WebGL을 지원하는 PC 브라우저가 필요합니다. `index.html`을 직접 더블클릭하면 실행되지 않습니다.

```sh
npm run build
npm run preview
```

빌드 결과는 `dist/`입니다. 배포 시 해당 폴더를 정적 웹 서버에 올릴 수 있습니다. 인터넷 연결은 최초 패키지 설치에만 필요합니다.

## 첫 플레이

1. 시작 위치 주변 도로의 청록색 세단에 접근하여 E로 탑승합니다. 스포츠카와 밴도 주변에 있습니다.
2. 금색 배송 마커 `(18,22)`에서 F로 미션을 확인하고 시작합니다.
3. 목적지 `(175,175)`에서 F로 물건을 수령합니다.
4. 자동차로 배송지 `(-175,-160)`에 도착하면 500을 받습니다.
5. 보라색 마커 `(-18,-140)`에서 경주를 시작하세요. 차량으로 5개의 체크포인트를 100초 안에 통과하면 1,000을 받습니다.
6. 빨간 마커 `(175,18)`에서 추격 탈출을 시작하면 수배 2단계가 됩니다. 150초 내 수배를 해제하면 1,500을 받습니다.
7. 청록색 판매점 `(18,180)`에서 차량을 구매하고 차고 `(18,65)`에서 불러오세요. 세단은 처음부터 소유합니다.

경찰의 시야를 벗어나면 14초마다 별이 하나 감소합니다. 건물 뒤에 숨거나 차량으로 거리를 벌리세요. 경찰이 가까이 붙어 저속으로 체포를 시도하면 체력이 감소합니다. 차량 내구도가 0이면 탑승자의 체력도 감소합니다.

## 현재 한계 / 다음 개선

이 버전은 작은 플레이어블 프로토타입입니다. 모든 이동과 미션 로직은 실제 코드로 동작하지만 상용 GTA 수준의 시뮬레이션은 아닙니다.

- NPC와 경찰은 단순 경유점 AI입니다. 교차로에서 겹침·정체가 생길 수 있으며 동적 우회, 차선 변경, 정교한 교통 신호 동기화는 후속 과제입니다.
- 보행자는 주로 인도를 왕복하며, 보행자끼리의 충돌과 고급 군중 경로 탐색은 없습니다. 멀리 있는 보행자는 숨기고 업데이트를 생략합니다. 차량 스트리밍은 없습니다.
- 차량 충돌은 단순 반경과 건물 AABB 기반이며 정밀 강체·서스펜션·차체 파손 모델은 없습니다.
- 경찰 시야는 거리와 건물 차폐 샘플링으로 판단합니다. 경찰 등급 상한은 현재 3이며 5단계는 추가 밸런싱과 UI 확장이 필요합니다.
- 상업·산업 구역은 기본 건물 형태 수준입니다. 창고 외형, 컨테이너, 상점 간판과 시설 표지판이 있습니다. 건물 내부·실내 상호작용·주유 기능은 아직 없습니다.
- 야간은 창문 발광·가로등·주변 점광원·야간 보조광을 사용합니다. 자동차 전조등의 실제 광원, 실시간 반사와 후처리 블룸은 아직 없습니다.
- 음향·대사·전투·의상·튜닝·주유·날씨·실내 공간은 미구현입니다.
- 현재 위치·체력·미션 도중 상태는 저장하지 않습니다. 브라우저/주소/포트를 바꾸면 저장 공간도 달라집니다.
- 차량을 멀리 두고 오거나 끼었을 때 일시정지 메뉴에서 시작 위치로 복귀하고 차고에서 소유 차량을 다시 출고할 수 있습니다.

## 검증

`npm run build`의 TypeScript 검사와 Vite 빌드를 통과했습니다. Chrome의 소프트웨어 WebGL 환경에서 시작 화면과 렌더링, 실제 키보드 탑승·가속·하차 입력을 실행했습니다. JavaScript 런타임 오류는 없었습니다.

별도 통합 검증에서는 위치·시간을 제어하여 배송 500 / 경주 1,000 / 탈출 1,500 지급, 경찰 생성과 실제 위치 이동, 수배 해제, 건물 충돌 조회, localStorage 기록을 확인했습니다. 이는 모든 미션을 사람이 처음부터 끝까지 주행했다는 의미는 아닙니다. 장시간 플레이·다양한 하드웨어·교통 교착 상황은 추가 테스트가 필요합니다.

### v1.1 검증 결과

TypeScript와 Vite 빌드를 통과했습니다. Chrome 소프트웨어 WebGL에서 도심/주택/공원/산업 구역의 낮·해 질 녘·밤 5개 화면을 캡처해 확인했으며, JavaScript 및 WebGL 셰이더 오류는 없었습니다. 실제 메뉴 입력으로 시간대 전환과 시간 고정, 일시정지 후 교통 유지도 확인했습니다. 기존 통합 검사에서 탑승·가속·하차, 세 가지 미션 보상, 경찰 생성·이동·수배 해제와 저장이 통과했습니다. 테스트 환경의 FPS는 GPU 성능을 대표하지 않습니다.

## GitHub 업로드와 자동 배포

`.github/workflows/deploy-pages.yml`에 GitHub Pages 자동 배포가 준비되어 있습니다. `main`에 소스를 올리면 고정된 의존성 설치(`npm ci`) → TypeScript 검사와 Vite 빌드 → Pages 업로드와 배포가 순서대로 실행됩니다.

저장소의 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택해야 합니다. 실제 사이트 주소는 성공한 배포 작업의 `github-pages` 환경에 표시됩니다. 아직 원격 저장소 생성이나 배포가 성공했다고 뜻하는 설정은 아닙니다.

Vite의 자산 경로를 상대 경로로 설정하여 저장소 하위 경로에서도 게임 파일이 로드됩니다. Git에 `node_modules`, `dist`, 로컬 환경 파일이나 중복 생성된 실행 HTML은 올리지 않습니다. 단일 HTML은 `npm run build:play`로 다시 생성할 수 있습니다.

공식 문서: [GitHub Pages 사용자 지정 워크플로](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [Vite 정적 배포](https://vite.dev/guide/static-deploy.html#github-pages)
